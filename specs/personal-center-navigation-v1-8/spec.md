# 1.8.0 个人中心与导航闭环

日期：2026-09-17。状态：draft（已确认入口需求，版本拆分及详设为本轮方案；未启动实现/生产操作）。

## 来源与基线

- 用户确认：将“聚义厅增加个人中心入口”落实到下一版本，并输出需求清单与详设。
- 由该需求派生：横竖屏入口、头像回退、返回聚义厅、经济预览返回个人中心、导航中的身份/生命周期保护。不是用户新增了资金、资料编辑或平台改造需求。
- 已发布1.7 API `9aaf2a315b0365ccf801012b100cf7b38cf47c62`，Web `7c4902983974b748ea01d7c88e2403fa636691e6`。这是设计参照，不是下版候选SHA。实施时核对最新develop差异，不覆盖新增提交。
- 已有 `/profile`（路由名UserProfile）、`/economy-preview` 和 `/juyiting`；个人中心已有基本资料、经济预览、登录与安全。增量是可发现性和双向导航，不重复开发这些功能。
- 1.7授权12表修复及限定范围线上回归通过，用户最终验收待回执；不因此归档全部经济需求。

## 非目标与保留需求

- 不新增资料编辑/头像上传、资金发放/交易/安装/托管开通、语音启用；不修改Agent客户端或isp-install。
- 不增加API、数据库表/迁移或生产数据回填，不补建未授权hosting两表。
- 不做跨刷新草稿同步、聊天后台续流新架构、地图像素位置持久化或任意URL返回。
- 旧1.8平台增强F03–F05/G01–G07仍未完成；本方案建议拆为后续独立列车，版本号另定，不删除原需求。模型/智力值、外单与技能候选治理仍draft；交易2.0、性能2.1与延期语音保留原边界。

## 完成定义

源码合develop/构建/部署/用户验收分别记录。入口可见且能从聚义厅走完个人中心、经济预览、返回路径；相关回归通过才通知验收。未测真机、非空数据和双真实账号必须明确，不把只读入口上线等同整个经济或平台版本完成。
