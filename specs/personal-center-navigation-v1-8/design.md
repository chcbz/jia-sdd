# 1.8.0 详设：个人中心与导航闭环

日期：2026-09-17；设计及实施修订；已完成候选代码与验证，未改线上配置。

## 1. 用户路径及页面职责

```text
聚义厅 /juyiting
  └─ 当前用户头像 +「个人中心」 → /profile
       ├─ 基本资料（现有只读）
       ├─ 经济预览（只读） → /economy-preview
       │    └─ 返回个人中心 → /profile
       ├─ 登录与安全（既有退出当前设备/全部设备）
       └─ 返回聚义厅 → /juyiting
```

复用UserProfile，不再造“我的”同义路由或新账号页。入口是登录用户，而非当前选中Agent的肖像。复用当前登录展示数据，昵称缺失回退账号/“个人中心”；头像无值或加载失败用通用账号图标，不额外获取用户目录。

### 1.1 聚义厅入口

- 竖屏：集成在HallPortraitHome既有header的右侧动作区；横屏：集成HallStage既有header或可见控制区。横屏会隐藏部分header，不能只在一个被CSS隐藏的节点增加按钮。
- 共享轻量展示组件 `HallAccountEntry.vue`（拟新增）；props仅头像/展示名，emit `open-profile`。由JuyiHall统一负责路由，不在地图engine内导航。
- 入口以头像+可辨认文字呈现；紧凑布局允许短文案“我的”，accessible name固定“个人中心”，桌面可有提示。沿用现有按钮触控尺寸并用真实交互验证，不新增拍脑袋的发布数值门槛。
- 使用button/RouterLink语义、键盘焦点和Enter/Space支持。入口占用自己的布局盒，不用全屏透明遮罩；操作不得传到地图触发拖动/点将。
- 安全区用现有viewport/safe-area策略。竖屏和横屏共用动作，但仅当前可见模式入口进入键盘顺序；被inert的底层不允许绕过活动弹窗。
- 可关闭弹窗时沿既有关闭路径返回主视图；保存/提交中遵守既有交互锁。不能用点击头像强行取消事务或绕过锁。

### 1.2 个人中心

- 页面标题“个人中心”，顶部常驻“返回聚义厅”；内容区独立纵向滚动，不改变全局高度。
- 按序复用：身份卡片/基本资料 → 经济预览卡片 → 登录与安全。经济卡片显示“只读，不扣款、不下单、不安装”，按钮“进入经济预览”。
- build开关未开启时不展示可点击预览入口；已开启但服务端capability失败/禁用时显示明确状态或重试提示，不静默弹回相同页面，不把失败当空目录。
- 本版只复用已有能力查询；不为个人中心额外并发加载钱包、所有商品、全部Agent权益。跳转经济页面后由原composable按需读。
- 保留退出所有设备二次确认、busy/错误提示、真正退出后的认证清理。不得把导航按钮接成退出。

### 1.3 经济预览及返回

- 页面header增加“返回个人中心”，与现有“刷新全部”并存；五个功能区业务语义不变。
- 固定目标为内部已知路由，不接收未经校验的returnUrl，也不把JWT、client、Agent权限放进URL。
- 所有显式返回按钮使用固定路由replace，避免 `profile↔preview` 产生无穷返回栈；向下进入使用push。浏览器原生后退保留正常语义，不额外劫持popstate。直达/刷新无需history长度也可返回。
- 若无认证，沿现有统一登录链路；登录后恢复目标只能采用内部路由白名单，不能放开任意外链。当前鉴权实现先盘点复用，不另写认证体系。

## 2. 状态、错误与安全合同

| 情况 | 行为 |
|---|---|
| 用户资料读取中/失败 | 入口仍可用，使用通用图标/文案；不得显示另一身份旧头像 |
| preview能力关闭 | 不触发业务写接口；显示未开放/当前不可用，能返回个人中心 |
| 401或身份切换 | 沿现有认证流程；清除本版导航快照与个人数据，旧请求取消/迟到结果丢弃 |
| 网络失败 | 保留准确失败和重试，不冒充0余额，不新增固定性能deadline |
| Agent/task已失效 | 返回后重新鉴权读取；无权限清除选中，不回退读其他scope |
| 重复点击/返回 | 路由动作去重，不自动重发聊天、建任务、点将或阅读写入 |

导航快照仅在同一会话内保存最小UI信息（例如原有选中ID/列表位置），绑定现有认证generation与scope，ID只是恢复线索，不是授权。优先使用已有store/生命周期；不新增localStorage敏感缓存。返回根据当前设备方向重新计算布局，旧方向不覆盖用户旋转。

**离开聚义厅风险须单独验证：**先检查现有聊天流、录音、表单草稿的路由卸载语义。不新增后台续流，不声称路由切换不影响现有流；存在未保存草稿或进行中的录音/流时，以既有状态展示一次明确离开确认（继续停留/离开并按原策略停止）。用户确认前不导航；确认后只清理此页面拥有的请求/资源，不能停止Agent任务或服务端作业。不得为一次普通跳转隐式发送草稿、补发消息或保存业务数据。无活动操作不弹确认。具体状态源在实现首包固定。
