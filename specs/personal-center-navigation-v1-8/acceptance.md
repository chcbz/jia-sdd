# 1.8.0 验收矩阵

2026-09-17；以下均为待执行标准，非PASS报告。

| ID | 场景 | 预期与证据 |
|---|---|---|
| A01 | 聚义厅竖屏/横屏 | 当前用户个人中心入口可见可点，桌面/触屏都到profile；真实截图与点击轨迹 |
| A02 | 无头像/坏头像/长昵称/资料失败 | 有默认图标，不溢出不泄漏旧身份，入口不受影响 |

| A06 | preview开关关闭/网络错误/401 | 说明准确，有返回/重试或原登录流程，不静默假成功 |

| A09 | 重进聚义厅/旋转/键盘 | 地图可重复挂载、当前方向正确，输入恢复不遮挡；不遗留renderer/监听 |
| A10 | 无障碍 | Tab可达、可见焦点、读屏名称明确、隐藏模式入口不可聚焦 |
| A11 | 原功能 | 名册/地图分流、点将显式target、聊天、典籍、只读预览及退出无新增缺陷 |
| A12 | 交付 | exact Web/API绑定、相关测试/制品SHA、发布readback及用户验收各自记录 |

匿名/第二身份/模拟capability错误可在隔离测试覆盖；线上仅使用用户明确授权的账号和已有数据，不复用聊天里历史明文凭据、不造生产数据。真机/双真实身份/非空商品缺少条件时明确未测，不能让仿真代替事实。涉及退出全部设备等副作用先限定专用测试会话或在隔离环境验证，不随意踢出现有用户。
