# Account self-service closure acceptance

- [ ] A user can target only their own account through a dedicated authenticated contract.
- [ ] Closure is idempotent, auditable and safe under retries, concurrency and partial failures.
- [ ] Sessions, authorization grants and API keys are invalidated according to the frozen state transition.
- [ ] Retained, anonymized and erased data exactly matches the approved policy across every dependency.
- [ ] Recovery and finalization semantics are explicit and independently reviewed.
- [ ] Production migration, rollback and smoke evidence is recorded against exact API/Web/root revisions.
