## 2. 范围与非目标

- 核心：无业务技能也能使用获准工具；隔离原生执行、原文件交付、真实成果提交/下载、必要恢复、技能固定视图、最小来源记录。
- 必交付能力：保留生图/改图/读图，读取和输出TXT/Markdown/HTML/CSV/JSON/XLSX/DOCX/PDF等约定文件，真实网页浏览/操作。媒体制作及提取复用按已确认扩展目标交付。
- 普通技能是经验包，不强迫生成动作manifest或新runner；新能力缺工具/依赖如实报告，不伪造READY。
- 非目标：新市场/工作流/微服务/审批、全部Provider通用平台、全项目存储重构、在线Office编辑器、远程桌面、任意第三方依赖自动安装、公开分享。
- 不以职责拆分删除已要求能力。删除的是越界实现和无需求功能；仍提供所需能力的算法迁至工具/技能后删除旧编排入口。

## 3. 单一执行链

```text
Web提交意图/材料
  → API接纳与固定权限、执行/输入/输出/技能集合
  → bridge隔离环境及引擎接线
  → 模型选择步骤，工具实际处理（技能可空）
  → bridge快照候选、核对提案/终态、上传/commit
  → API持久业务完成/投影
  → Web按明确执行引用显示/下载
```

API不是引擎进程管理器，bridge不是图片/视频业务编排器，工具不是权限/任务状态权威，模型不是业务完成权威，Web不能从模型文字推断交付。
