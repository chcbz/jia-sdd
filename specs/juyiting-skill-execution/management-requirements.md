## 1. 要解决的问题

用户应能在所选Agent的一张技能列表内，判断“有什么、能不能用、为何不能用、能装什么、能否升级”，并完成安装、升级、启停与异常恢复；不需要理解安装器、命令投递或Runtime目录结构。

系统必须区分：源码有新版、平台已批准发布、用户有权益、包已安装、指定版本已激活、当前Runtime可运行、某个任务获准执行。任何一项都不能替代其他事实。

## 2. 范围与角色

### 首期交付

- Agent详情的单一“管理技能”入口与同页统一列表。
- 可信管理读模型、发布候选与差异、权限和购买费用确认。
- 首次安装、受控升级、停用/启用、新调用准入、在途任务版本固定。
- 离线等待、真实进度、失败分类/原操作重试、未知核对、刷新恢复和审计历史。
- 五项UX修正、跨端状态/安全合同、相关测试和版本化交付准备。

启停从前期缺口草案的后续项纳入首期，避免原型功能与正式交付清单不一致。2026-10-26用户将受控卸载纳入本期；人工降级/回退与完整平台维护页仍属于后续，不以隐藏按钮声称完成。

### 用户角色

| 用户 | 可以做 | 不可以做 |
| --- | --- | --- |
| Agent Owner | 查看自己Agent的管理事实，按后端允许动作安装/升级/启停/恢复 | 管理别人Agent、自行发布平台包、修改包声明获得权限 |
| 外单委托人/普通任务参与者 | 只按任务ACL使用承办Agent已授权能力、看任务相关结果 | 因“可接外单”而购买/安装/更换该Agent技能 |
| 平台维护者 | 沿现有受控发布权限维护批准版本；后续维护页提供相同权限入口 | 普通Owner接口隐式绕过归属；上传未批准包即授权执行 |
| Runtime | 报告当前安装/能力事实，执行精确授权操作 | 以本地扫描、SKILL.md或自报版本替代平台权益/任务授权 |

### 非目标

不新建商城、微服务、消息队列、DAG、通用插件市场或常驻扫描服务；不引入按运行费用审批/冻结/预扣；不批量自动升级；不允许任意URL或本地包直接变成平台授权技能；不修改成果验收语义；不自动重发之前失败的议事消息。

本方案不吞并最初“事项黄色区域”“吴用回话失败”“资料弹框”等独立任务。技能声明、版本和就绪原因改善与其有关，但不能宣称解决了全部原反馈。

## 4. 关键场景与不变量

### 4.1 安装

列表点安装 → 原行显示能力/购买费用规则与权限 → 必要权限批准后后台获取权威报价 → 原行一次明确确认 → 已接纳后显示原操作状态 → 精确安装事实与当前目录核验 → 更新列表/详情。

报价是准备动作，不扣费；不再增加常驻“获取报价”页面或总入口。报价失败在原位置重试；最终确认才授予本次购买/安装操作。未接纳时可收起；已接纳后收起/关闭不是取消。

### 4.2 升级

原行展示批准目标及紧凑差异 → 新增权限/费用单独明确 → 一次确认 → 先准备候选，旧版继续服务 → 短暂阻止不确定的新准入、受控切换、核验 → 后续新请求用新版。

旧执行使用原授权/原包；准备失败保留旧版。切换已发生但回执未知不能假装“升级失败，已恢复旧版”。源码1.1.0存在不等于已发布；版本候选按发布事实选取，不按字符串大小或目录名猜测。

### 4.3 停用与启用

停用仅阻止新调用，不退费、不卸载、不取消已经准入的普通执行；说明影响并在同一行确认。启用不复制安装：核验权益、精确包、当前Runtime目录与依赖后恢复新准入；离线可记录期望，不能显示已可调用。

### 4.4 失败与未知

- 已证实未激活且财务未终结：允许原操作受控新尝试，不再次购买；保留失败attempt证据。
- 已退款/权益终结：原操作只能查看；重新安装是新的显式报价/授权流程，不伪装成重试。
- 不知道是否受理或切换：核对原requestId/operationId；不能新建替代操作、自动退款、升级到另一目标或调用Provider。
- 所有恢复都重新校验当前身份/资源范围；关窗和身份切换不扩大后台权限。

## 5. 已定设计与尚待事实核验

**本方案默认决定**：同页列表；一次只展开一个技能；报价后台准备；未提交草稿只在当前窗口保留；刷新只恢复已提交操作索引；首期包含启停；支持合法已绑定Agent离线排队；普通升级保留在途包；未知只恢复原逻辑操作。这些是目标合同，不是对现有代码的描述。

**实施前须查清但不靠臆测补值**：真实商品发布状态、各版本升级权益/价格策略、最新远端对本模块的变更、当前数据库约束与可信安装记录覆盖、当前三端线上版本与Runtime安装输入。未知升级价格不能默认免费；未知运行费用仍不成为执行拒绝理由。

现行原型示例的PDF正文提取不含OCR；文本生成示例不等于真实商品已上架。首次上线验收使用真实批准包，未上架示例不进入产品目录。
