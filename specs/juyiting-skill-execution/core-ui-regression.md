- 全轮钱包预算不超过用户授权余额；当前授权整轮累计100文，已经消耗的批次不能重置预算。2026-11-10 R5新增1文、截至R5累计8文；后续执行读取真实台账，不能照抄此数重置预算。方案正文里的“预算120文”是测试数据，不代表测试钱包消费授权。

- 失败保留原操作状态，不补催“继续生成”后将原自动续轮改为通过。依赖失败的后续用例记BLOCKED。截图标题、状态或模型自述不能替代实际工具/文件证据。
