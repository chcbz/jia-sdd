# 聚义厅竖屏只读动态地图预览

日期：2026-09-06。用户授权：详细设计、任务安排并实施。

## 问题与目标
当前发布 Web `101ac4c6a2b49d04771dedef52af893c72f98c09` / tree `93c561b90b8d921889206ba69ea747d5fc4c328c` 的 `HallPortraitHome.vue` 使用 CSS 色块和最多四名人物按钮，不是真地图。
将该区域替换为横屏地图的只读缩小视图：同地图、同人物表现和当前页面的同一运动状态；竖屏保留快捷调度、横屏保留探索操作。

## 范围
- 同版本 TMX、图层、遮挡和人物资产；不另画简化地图，不以录屏/静态截图冒充实时场景。
- 竖屏全景 contain 镜头，禁止地图手势/点选/快捷键；独立“横屏看全景”按钮。
- 横竖屏切换不重新生成角色位置、巡逻进度或第二个命令消费者。
- 加载、异常、暂停和空数据状态明确；预览失败不影响快捷入口和横屏按钮。
- 性能节流、页面后台/离屏策略、模式切换与组件销毁清理。

## 非目标
不改变屏幕方向策略、不引入 CSS 旋转、不强开原生横屏；不改后端、数据库、Agent 协议、任务结算、语音开关或服务监控；不承诺跨设备位置同步。
“实时”仅指当前页面已有地图角色运动。当前地图中的本地巡逻/演示角色仍是原有表现，不得包装成后端真实任务遥测。
