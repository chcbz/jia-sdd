# D3验收清单

D3-AC编号不沿用旧58项，避免把已撤范围继续当门禁。以下全部 **NOT_RUN**；历史原型和生产只读证据不替代业务验证。

| 编号 | 用例与预期 |
|---|---|
| D3-AC01 | 同用户两个Agent四种开关组合独立；默认关闭、改名不影响、重绑不继承；无固定角色名/账号判断 |
| D3-AC02 | 只能修改本人开关；加载失败不当关闭，超时原key恢复、并发版本冲突不互相覆盖 |
| D3-AC03 | 本人Agent始终可候选；他人仅同平台开放目标可候选；全部合法候选可达，展示公开所属用户，不暴露私有安装信息 |
| D3-AC04 | 任务类型不限，能力/推荐失败/离线/忙碌/成本未知不阻止委派；真实运行能力不足如实报错 |
| D3-AC05 | 本人及他人均使用同一个point-and-deliberate；选中不执行、确认自动首轮，无二次启动或服务方审批 |
| D3-AC06 | 当前任务资料明确展示并冻结版本；无资料任务可提交；确认后资料变动冲突重确认，不读取其他任务/私聊/整个文件库 |
| D3-AC07 | 重复点击、请求超时、断线、outbox重投不重复创建委派/首轮/实际效果；按原操作回执恢复真实状态 |
| D3-AC08 | 关单与提交竞态有确定事务顺序；关闭后新外单拒绝、本人任务与已接外单继续；目标不在候选仍可继续原任务 |
| D3-AC09 | A任务由B Agent执行；无关C、B的其他Agent、旧绑定/旧session不能领取、读文件、回报或冒充A；B用户不因宿主身份获得页面正文权限 |
| D3-AC10 | HTTP领取/输入/effect/结果/恢复及WS出站/ACK/receipt/delta/final/stop全部验证A数据、B认证，错误及迟到回报不串任务 |
| D3-AC11 | 离线/忙碌委派后沿原队列恢复；前端准确区分提交与实际运行，不显示伪成功 |
| D3-AC12 | 文本与带文件任务从委派到真实成果、继续交流及原验收闭环；不新增图片专属通道 |
| D3-AC13 | 取消/停止只提供原actions允许的能力，不出现服务方撤单；既有授权代际/失效规则对两类目标一致 |
| D3-AC14 | 本人原任务/私人密议/管理能力不回归；PC/移动、账号切换、迟到响应不串身份；无新增费用门槛 |
| D3-AC15 | 迁移及历史/活动本人授权可恢复；原版本无效回报不能写新授权；不靠owner缺省回退掩盖字段缺失 |
| D3-AC16 | 实施后的正式测试匹配固定源码与Flow证据；若获授权发布，安装制品/三端版本及真实跨账号在线结果可核验 |

这些是归组验收，不表示只需16个自动化断言。安全、事务和恢复的具体测试按实际修改路径展开，不复活已移出范围的产品能力。
