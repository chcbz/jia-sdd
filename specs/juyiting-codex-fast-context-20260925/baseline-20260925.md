## Contract freeze

- `POST /chat/stream` may accept only `chat` or `inspect` interaction hints; text must never authorize `EXECUTE`.
- Existing durable Hall Draft / personal workspace / `command.dispatch` paths remain the only execution authorization paths.
- API owns scope validation, source vectors, context snapshot identity and generation fencing.
- Codex threads are disposable inference caches, never business truth.
- New fields and events are additive and capability-negotiated; old Web and old Agent paths remain supported.
- Fast CHAT must be labelled from measured capability evidence. Until strict tool absence is proven, the runtime label is `read-only-constrained`, not “no tools”.
- Slow generation is observed and queued; it is not cancelled merely to satisfy a latency target.
