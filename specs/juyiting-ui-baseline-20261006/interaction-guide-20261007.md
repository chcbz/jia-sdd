# 交互说明与新需求定位 · 2026-10-07

## 本轮唯一基准

使用本目录 `prototype/index.html`，继续保留10月6日优化布局与浅色圆角标签；不再以多媒体 SDD 的 `adjusted` 或 `complete-20261007` 为主入口。页面和状态编号见 [coverage.md](coverage.md) 与 [可点击索引](prototype/pages.html)。

## 最短流程

1. P01/P03 输入需求，也可以只添加附件；资料选择取消不提交，确认后才加入草稿。
2. 提交成功清空创建草稿，P04 选择好汉并点将；P06 同一事项内澄清需求。
3. 预览图片、播放示例音频、下载文档/文字；保存到资料是可选步骤。引用成果后补充修改意见，生成示例新稿。
4. 顶部返回 P05，查看正式成果与验收；无需先保存或勾选成果。
5. 确认后冻结本次成果与唯一操作，首页立即显示完成；刷新保持完成、只读，不自动重复提交。

## 其他交互

- 三种会话：正式议事、每位好汉的密议、厅前公议分别保存消息、附件、引用与草稿，不串到正式验收。
- 话头：另起前确认，取消保持当前内容；确认保存快照，记录中可恢复或逐项删除；删除话头不删除事项。
- 输入栏：左侧＋后直接显示添加资料图标，右侧语音图标紧靠发送；顶部三个话头图标靠右。图标可悬停查看名称、使用键盘操作。
- 语音：仅示意录音/转写，可取消、追加、替换、丢弃，不自动发送。＋中保留“语音回答”与AI告知，不含识别语言设置；资料入口已经外置，不再藏在＋中。
- 资料：逐文件预览、示例下载、重命名、回收确认、回收站恢复、引用到需求草稿；不操作真实文件。
- 典籍：书架、检索空态/结果、案卷引用；阅读器两章示例、目录、书签、手札在本标签保存。
- 我的/帮助：现有全部入口可访问18页；账号、安装、支付和地图实时交互只展示边界，不伪造执行结果。

## 失败与恢复

S10–S12 保留创建或发送的正文/附件；查原状态不自动重发。S13/S14 保留原验收operation和冻结成果，刷新或查询不创建第二次验收。S15明确显示 R01 独立root关联待实现，禁止伪报成功。

这些是目标交互的离线演示，不证明产品已具备幂等、事务或长期恢复能力。产品待办仍在多媒体 SDD 的 `remaining-tasks-20261007.md`，真实业务结论仍为 NOT_COMPLETE。

## 状态保存与重置

使用当前标签页 sessionStorage，按scenario隔离。普通刷新保留状态，不重发；索引里的代表性链接带 `reset=1`，仅首次打开清该场景示例，加载后移除reset参数，再刷新不会重复清空。不需要测试账号，不上传资料，不访问业务API。

## 怎样提出新需求

请描述“页面编号 + 状态编号 + 点击的操作 + 当前问题 + 期望结果”。例如：**P06/S08，点击图片的引用修改，希望输入区引用卡片同时显示图片缩略图。** 没有编号的新要求也可以直接描述；新增业务能力需另写契约与实现任务，不能把原型模拟当上线验收。
