# 正式环境与当前交互原型差异 · 2026-10-07

## 结论与取样边界

**不是全部一致，也不是所有差异都需要把生产改成原型。** 首页浅色圆角标签本轮已在线观察到；最新议事精简、外置资料、右侧纯图标语音和统一图标规格仍只在原型。完成态恢复与重复正文属于真实页面问题；典籍、地图、账号等则有生产比离线示例更完整的部分。

- 生产入口：`https://kit.chaoyoufan.cn/juyiting`；原型：[当前唯一入口](prototype/index.html#home)。不是 `adjusted` 或 `complete-20261007`。
- 本轮真实 Chromium，桌面1440、手机视口390；原型另外取样18页及完成态。**没有重做完整业务闭环，没有真机/键盘验证，也没有本轮320px线上走查。**
- 生产15页/入口取样；P07密议、P08独立公议、P13阅读器正文未进入，原因见矩阵。页面进入不等于其所有操作已验收。
- 没有主动创建、点将、发送、保存、上传、验收、改名、回收、安装、扣费或启用麦克风。复用用户授权的测试账号，认证不记凭据；资料选择只打开并取消。正常页面加载包含查询型POST，不能说“零POST”。
- 初始复用本聊天浏览器，遇到认证失效与后台截图停滞，之后换本轮独立临时浏览器/独立认证；没有重启、关闭旧浏览器或原型服务。失败/被遮挡点击保留在动作日志，不当产品失败或PASS。
- 证据：[当前任务只读核对](evidence/production-diff-20261007/current-task-readback.json)、[尺寸与差异数据](evidence/production-diff-20261007/comparison-metrics.json)、[动作记录](evidence/production-diff-20261007/actions.jsonl)。网络为各动作连接窗口取样，不是全程抓包。
