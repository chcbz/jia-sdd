# 聚义厅当前版本界面原型基准（2026-10-06）

## 目标

把当前聚义厅的一级页面、可达二级入口和主要议事状态整理成一份可重复打开的离线原型，作为后续界面优化的固定对照，而不是另起一套产品设计。

## 范围

- 保留办事 / 事项 / 资料 / 我的一级结构、桌面侧栏、移动底栏和现有弹层入口。
- 补齐提出需求、点将、事项详情、三类议事、成果、资料选择、资料管理、典籍、消息、招贤令、地图与个人中心边界。
- 固定本次已经确认的四项议事界面调整，不将旧 10 月 4 日原型中的旧输入方式作为后续基准。
- 记录源码 revision、素材来源、页面覆盖和模拟边界，避免把原型、源码候选和线上版本混为一谈。

## 非目标

不修改 Web/API 业务源码，不改鉴权、接口、任务状态或语音逻辑；不运行生产构建、流水线、部署、真实支付、绑定、麦克风、Agent 或 Provider。个人中心外部页面、实时游戏、系统软键盘与小程序原生方向不在离线原型模拟范围。
