1. 验收完成后事项不在当前筛选页，选中详情未被列表刷新更新。修复：按原ID重读一次，校验回执最小taskVersion、选中事项和身份；首页复用原readRevision刷新。不能以隐藏DOM/HTTP成功证明返回可见页正确。
