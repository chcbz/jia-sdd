整理：2026-10-23。本次仅整理文档，未重新查询源码、部署或在线状态；保留的源码基线见同目录 code-baseline.json，历史验收各自绑定版本。当前页面控件以 [Web 原型规格](../../../web/prototypes/juyiting/specs/prototype-spec.md) 为准。

## 目标与非目标

提需求 → 指定 Agent → 同一议事交互 → 交付 → 用户明确验收。四主状态为待点将、进行中、待验收、已完成；排队/澄清/异常提供真实原因，不扩成审批状态机。取消及异常历史仍可查询，不伪装成进行中。

本轮不增加新用户引导、知识库新写入口、收费系统、Runtime框架或多Agent聚合状态机。业务身份、ACL、锁、幂等、事务和未知执行恢复不可删减。

## 使用帮助（2026-11-09）

用户已确认原型并授权实施。P17为独立帮助首页，涵盖快速入门、五类主题、关键词/同义词搜索、九篇文章、业务入口导航、现有新手引导重播和既有反馈接口。Web只负责内容与交互，不持有业务授权，不通过帮助触发创建、重试、扣费或验收。反馈复用原FormData字段合同，成功依据真实回执，失败保留内容、未知结果不自动重放，身份变化清理局部状态。

手机全屏/桌面面板沿用Hall；Hall统一负责返回和焦点，组件维护文章/反馈子页。帮助跳转到已存在来源恢复原frame，否则打开业务入口根，避免耗尽名册/事项详情层级。重播仅临时隐藏帮助，不清空原frame、草稿或引导完成记录。原型固定入口`web/prototypes/juyiting/index.html#help`，反馈原型仍明确离线演示。 “我的”页帮助入口与其余常用入口统一放在同一mine-grid，复用卡片背景/边框/圆角/字号/间距与两列或单列响应式，不再使用独立页脚样式和右箭头（2026-11-09截图修正，源码8b1b77c/1.16.134已获授权部署，72项测试及369/390/1440浏览器样式回归通过；613安装文件和256线上资源摘要核验通过，登录后交互未线上实测）。

## 当前交互定案

- 创建入口统一；保存成功后待点将，选择候选不提交，确认承办才自动办理，不增加二次启动。
- 修改通过原议事表达，普通问答不改变待验收；不恢复“引用修改/继续修改”专用按钮。语义不清才澄清，后端控制状态。
- 验收采用 [成果选择设计](../../juyiting-external-commission-mvp/design.md#selected-output-acceptance)：工具栏打开可多选成果列表且默认不选；卡片“验收此版”只预选该版本。确认才写入，历史版不按时间排除，关闭不提交；提交与验收分别恢复，不能因模型回复或重新挂载自动验收。
- 事项筛选单行横向滚动，不增加统计行；议事消息区优先占空间。验收图标位于工具栏，与相邻图标同尺寸，不进输入框、不用红色大按钮。
- 待验收详情保留资料信息，验收入口不重复；办事首页和事项列表进入同一链路，不进入废弃验收页面。
- 选择资料无下载按钮；“已选x份资料”旁并列上传、拍照和相册纯图标入口，不显示文字、底色和边框，保留44×44点击区、title及无障碍名称；拍照优先后置相机且单张，相册多选图片不强制拍照，上传仍接收原有文件类型。三入口共用串行上传和结果核对；上传中或原上传未确认时一起禁用，窄屏允许换行。取消系统选择不改原暂存；相机/相册实际由设备和浏览器提供，不承诺桌面强制调用摄像头。上传 COMMITTED 后按 fileId/version 刷新列表并自动选中；未知操作查询原意图，不能重复上传。取消/完成保留原布局，说明文字仅写规格。移动预览可切换/收起；已选资料直接预览，不重新打开选择器。
- 有返回不再显示重复X；无返回的独立弹层仍可关闭。停止回复与取消事项区分，不承诺撤回已发生的副作用；已完成只读，不继续催验收。
- 存储无业务格式/MIME白名单，但保留安全/权限/完整性控制；存储、预览、解析、编辑能力分别判断。后续已取消PPT/PPTX在线渲染，保留上传/下载/生成；本会话PDF复验暂停，不扩大为删除PDF功能。
