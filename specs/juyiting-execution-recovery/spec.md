# 聚义厅执行回执与恢复（2026-09-21）

> 文档收口（2026-10-23）：保留执行回执只读核对合同、contract-pilot工具及证据，不清未知执行。 本轮仅核对文档归属与覆盖，不重新验证源码/上线；执行规则以根AGENTS为准。


## 依据与范围
用户在真实线上测试后要求继续：追查现有唯一执行、修复提交回执和刷新恢复。初测及授权补测见 `deliverables/design/juyiting-ux-test-20260921/实测报告与业务优化方案.md` 第13节。

本轮只新增只读历史/原请求核对 API，接回同窗执行反馈、服务端记录恢复及幂等意图保护，修复关联文件详情入口，并修补已存在 runtime failure API 的精确鉴权路径遗漏。不新增生成、不重放执行，不改 Provider、权限主体、业务状态机或现有生产数据。

## 业务目标
一次明确委托有回执、能查进度、刷新仍可找到；未知不等于未提交，失败不伪装为排队成功。界面继承聚义厅风格，不另建任务系统或重新堆叠功能卡片。

## 非目标
不保证本轮恢复已有失败运行的服务端终态，不做生产 DML，不调用代替 runtime 的失败上报；不购买、部署或重启 Agent 客户端，不新增收费生成/返工；不把单账号结果推广为转化率/收益证明。
