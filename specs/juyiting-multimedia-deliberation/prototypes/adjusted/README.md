## 保留什么

直接复用现状原型的实际 DOM 和三份部署 CSS，只替换本次功能区域。保留红褐色主题、桌面侧栏、移动底栏“办事 / 事项 / 资料 / 我的”、现有点将册和浮层议事，不新增顶部原型菜单或步骤导航。`current/` 未修改。

## 七项改动

| 范围 | 调整版行为 |
|---|---|
| 提需求 | 首页和张榜表单统一“添加资料（可选）”；工作空间多选图片、文档、音频、文本，支持预览、移除；取消选择不改变之前确认的附件。无资料也可提交。 |
| 点将 | 沿用点将册，只显示好汉信息，不显示当前需求和资料；明确选择好汉后“点将并议事”；自动新增悬赏议事，首条消息带入需求和资料。 |
| 普通会话 | 输入区域融合成一个框，只保留“＋”和发送；资料、语音输入与设置收进“＋”。议事内不放事项资料、百宝箱、验收按钮。取消独立参考图、生成图片、受控请求和再次开始办理等入口。模拟直接回复或自然澄清。 |
| 继续调整 | 同会话发送文字、只发附件或引用某一稿修改；旧稿保留。 |
| 多媒体 | 等待回复后在消息中显示图片、音频、文档或文字；图片放大、原生音频播放、文件预览、真实示例文件下载。 |
| 可选保存 | 成果或展开“保存文字片段”后保存到现有百宝箱；已保存内容可再次作为资料选择。保存不影响验收资格。 |
| 验收 | 仅在事项详情保留“查看正式成果与验收”。默认展示本次完成答复的交付清单，收起多选；需要换稿或增减成果才展开“调整交付内容”。确认后详情和列表显示完成，验收结果只列最终选定项。 |

## 快速体验

1. 首页输入“画一只鸟”，可选添加资料，点击“开始办事”。
2. 点将册选公孙胜，点击“点将并议事”，自动收到示例成果。
3. 点击成果“引用修改”，输入“把这一稿改成黄色，再附上音频和活动方案，以及文字介绍”，发送。
4. 在会话中预览、下载；需要时保存到百宝箱，不保存也可继续。
5. 通过原有“返回”回到事项详情，点击“查看正式成果与验收”，查看交付清单后确认完成；需要换稿时再展开“调整交付内容”。

其他分支：输入“帮我”演示自然澄清；输入“只需要一段文字介绍”演示纯文字交付。当前入口仍保留其他产品功能，但未纳入本次范围的按钮只说明演示边界。

## 模拟边界与检查

- 不加载生产应用 JS，不读取账号配置，不连接 Agent / Provider，不执行支付或真实业务写入。
- 回复是本地关键词分支，不是通用模型能力；图片是已有 SVG 示意插画，第二稿替换颜色；音频是两秒合成示意音，不是鸟鸣或真实配音；文档和文字是静态示例。所有下载与对应预览文件一致。
- 页面状态仅保存在当前标签的内存中；刷新重置，不冒充持久化工作空间。原型一次演示一个任务，历史事项列表其余行仅保留现状外观。
- 语音输入和设置收进输入框“＋”菜单，但不启用麦克风。未演示的文件格式、失败恢复、真实流式事件与 Agent 文件读写仍需产品开发和正式测试。
- 系统 Chromium 133 检查完整交互，覆盖 1440 / 390 / 320 宽度，含真实点击底栏、附件选择取消/移除、引用多轮、图片/音频/文档/文本下载、音频播放、可选保存、纯文字且不保存的验收。
- 复核脚本：`check.cjs`；使用现有原型 HTTP 服务，`PROTOTYPE_ORIGIN` 可指定同类服务根地址。仅轻量原型诊断，不运行 Vite/Gradle 构建或 Flow，不替代产品验收。

## 改动标注

`annotations/` 单独提供只读说明页，圈出 11 个界面状态的变化，包含桌面/手机两套截图与编号说明。它不向产品原型新增菜单，也不改变原有交互。红框位置按对应截图的实际 DOM 范围采集；截图只是离线示例。标注页经 1440 / 390 / 320 宽度检查，支持切换界面、隐藏红框和点击编号定位说明。

## 本轮进一步简化

- “事项”三个创建按钮融合为一个“提出需求”，表单提交统一为“提交需求”；不改真实后端类型/权限。
- 议事移除三个导航快捷按钮，输入区只保留“＋”与发送，返回事项详情验收。
- 点将册不显示需求和资料，只显示所选好汉信息与点将动作。
- 验收默认展示交付清单，多选只在用户主动展开“调整交付内容”时出现。
