## 1. 身份、应用与区域

| 场景 | 预期 |
| --- | --- |
| 同 client、同用户分别进入 0/1/2 | 获准区域可进入，token单区绑定，数据不混；不能只靠不同client证明隔离 |
| Web/移动端两个已授权client，同tenant/domain/owner | DOMAIN域可访问同一对象；LEGACY域仍严格原client，不隐式共享 |
| 同tenant但client无数据域grant，或用户非成员 | 服务端拒绝，知晓tenant/client_id不能授权 |
| 用户是0管理员但不是1成员 | 不能进1或管理1；0不是全局权限 |
| 修改tenant_hint/header/body/localStorage/JWT | 选区仍验成员/grant；业务覆盖拒绝，签名篡改401 |
| 授权码绑定1，兑换/refresh试图改2 | 拒绝，code不能重用；选区POST有会话/CSRF/事务绑定 |
| 撤销成员/client grant与业务写并发 | 提交边界明确，撤销后无新准入；流中止，不能等token自然到期 |
| 旧无tenant token用于多区client | 切区启用前停止旧兼容；限时单区映射不扩散到TEST |
| 共享API登记0/1/2，本地仅登记1 | 合法身份可访问共享对应区；0/2到本地拒绝，反之1到共享可按授权成功 |
| API Key/Agent/机器token换tenant或owner | 与注册/执行记录不符拒绝，不自动继承用户选区权限 |

## 3. 前端与控制并发

| 场景 | 预期 |
| --- | --- |
| /resource失败、身份不符、存储失败 | 候选token不进入最终存储/业务请求，不污染其他身份 |
| 同namespace两窗口登录/登出/迟到回调 | IndexedDB持久revision/txn CAS，墓碑防ABA，只有当前事务可提交 |

| 同origin不同client或相同client权限降低后恢复缓存 | 浏览器按client隔离并复核成员/grant/scope指纹，旧私有缓存清除，不复用高权限内容 |
| 同client两个窗口分别停留0和1 | tab独立区域；切区不强制其他窗口切区；清理仅目标身份范围 |
| 切区时晚到文本流/语音/上传/预览 | 旧请求取消或结果丢弃；业务namespace和持久revision双重检查 |
| 本地默认1但用户无权限 | 明确拒绝，不悄悄回退0；显示区域名与TEST标识 |
| 控制操作相同key并发/丢响应 | 锁内幂等先于If-Match；同hash返回原快照，不同hash409 |
| 关闭与写入/领取并发 | 关闭提交后无新准入；控制行优先锁序无反向锁环 |
| BEGIN_DRAIN晚于关闭写入、cutoff时lease无效 | 不重置期限，不扩大集合，不复活过期lease |
| 区域重新开放、旧token/旧积压重放 | 新tenantSessionEpoch/admissionEpoch；旧身份重授权，积压不自动执行 |
| 停止本地部署1，区域1仍被共享服务使用 | 只停止该部署领取/进程；区域1和其他区域继续服务 |
| 暂停区域1，共享进程同时服务0/2 | 仅1被限制；不是停整个共享服务 |
| 部署重启/撤销/代次变化 | 不能绕过持久drain状态或自行领取新代次，和区域恢复独立 |
