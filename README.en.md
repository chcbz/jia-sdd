# JIA SDD Workspace

This repository coordinates the JIA backend and frontend as Git submodules. It contains cross-repository specifications, operational documentation, and reproducible integrated delivery baselines.

- `api/`: Java/Gradle backend
- `web/`: Vue frontend
- `specs/`: feature specification, design, task, and acceptance records

Clone with submodules:

```bash
git clone --recurse-submodules https://gitee.com/chcbz/jia-sdd.git
```
