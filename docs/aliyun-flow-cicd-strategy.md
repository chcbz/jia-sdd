# CYF 构建、制品与发布策略

现行入口核对：2026-11-10。文件名为历史延续，**不是Flow-only策略**。项目从2026-11-06默认本地测试/构建/打包/受控安装，2026-11-09单次计时规则优先；具体见[根AGENTS](../AGENTS.md)。

## 不变要求

制品须绑定完整源码commit/tree、版本、必要测试及SHA-256；复用必须输入与证据一致。普通磁盘构建，不用内存盘，不从脏目录或生产程序目录编译，不借旧receipt伪造本批成功。

单次单测/构建发布600秒，异常重试经归因另计，保留真实失败；回归不限时，不向业务/服务下传deadline。工具是否已按新计时规则适配须按入口核实，不能只靠规则更新推断。超限例外及生产/收费授权仍按根规则。

Flow仅在另有实际授权时使用，不自动触发/恢复额度后自动切回、不取消他人Run。历史Run、release profile、缓存与耗时实验仅证明当时输入；若复用其仍适用测试选择，须核对实际源码/变更影响，不把同Run历史结果当本地或当前证据。
