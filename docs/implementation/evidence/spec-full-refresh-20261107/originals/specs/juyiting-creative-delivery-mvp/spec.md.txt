## 用户目标

根据用户本轮确认，MVP 至少应面向真实可用的成果，而不是仅供观看的协作 Demo：

1. 根据用户需求生成图片。
2. 基于用户提供的图片，按要求修改图片。
3. 根据用户提供的信息，生成可下载的 PPT。
4. 上传用户已有的 PPT、Word、PDF、Excel，让 Agent 读取并通过对话修改，交付可预览、可下载的新文件；不限定为本系统生成的文件。

5. 每个用户在个人工作空间统一管理上传资料与 Agent 交付件；文件可先上传独立保存，之后按需关联自己的悬赏任务。

上述场景纳入目标范围，可以分批验收；各格式读取、修改、预览和导出须分别标注能力与验收状态，不能以“能上传”代表“能处理”，也不能以单一场景成功宣布全部 MVP 已完成。

## 交互边界（2026-09-18 用户补充）

以 **Agent 对话生成和修改** 为主要操作方式；用户上传原图/资料，在对话中描述要求，查看成果后继续通过对话提出修改。界面负责材料上传、进度、成果预览/下载和历史版本选择，不建设图片手工编辑画布或 PPT 内容编辑器。成果卡片的“继续修改”只定位源成果并进入对话，不打开在线编辑器。

## 个人工作空间（最新业务中心）

文件属于用户的个人空间，不必先发布悬赏。空间、对话和任务页展示同一文件/成果及版本；上传原件与 Agent 交付分清来源。任务关联是可选关系，可在多条本人任务复用明确版本；Agent 只能处理本次选定并授权的文件。这里不是 Agent 的服务器目录或 Git worktree。详细设计见 `workspace-design.md`。

## 产品承诺

用户上传/从个人空间选择资料（可不关联悬赏），说需求 → 系统明确目标 Agent 与能力/成本边界 → 真实生成或编辑 → 自动保存到个人空间并记录任务/会话来源 → 预览/下载 → 提出修改 → 新版本 → 确认结果。刷新、重新登录和 Agent 离线后仍能领取已保存成果，不需要开发者搬文件或补状态。

| 场景 | 最小输入 | 必须交付 | 不能用来代替交付 |
| --- | --- | --- | --- |
| 图片生成 | 用途、画面描述；风格/比例可采用可见默认值 | 可预览和下载的真实图片；格式、尺寸、版本可查 | 提示词、图片描述、示例图库、无法领取的临时链接 |
| 图片修改 | 原图、修改指令、希望保留的内容 | 实际基于原图的修改版、原图/结果对照、原图保留、版本化下载 | 丢掉原图另生成一张，或只回复“已修改” |
| PPT 生成 | 主题与用户材料；受众、用途、页数偏好可澄清/默认 | 可下载并正常打开的 `.pptx`；正文可编辑，用户图片/素材正常显示 | 文字大纲、HTML、PDF、整套页面截图或改后缀的假 PPT |
| 已有文件读取与修改 | 上传 PPT、Word、PDF、Excel，说明目标和保留要求 | Agent 实际读取内容、完成约定修改、说明改动，提供原件和新版本的预览/下载 | 只存附件、只给修改建议、未读取源文件另写一份、静默丢内容或换格式 |

`.pptx` 正文可编辑是本方案采用的实用性验收默认值；这里指下载后可在办公软件中编辑，不要求用户手工编辑，也不要求产品提供网页内编辑能力。业务效果仍由用户按原始要求确认，文件可打开不等于内容已验收。

## 范围

- 个人工作空间：上传与交付统一管理，名称搜索/类型来源任务筛选、重命名、版本、预览下载、回收站/恢复；关联悬赏可选，执行仍有内部 task/run。
- 统一文件上传与自然语言入口，覆盖图片、PPT、Word、PDF、Excel；能力可用性说明、必要澄清、输入资料/原图的安全接入。
- 真实 Agent/工具执行及状态反馈；模型调用与文件生成/编辑链路的接线。
- 复用既有任务、身份、artifact、成果列表与正式验收；文件生成、保存、预览、下载和修改版本贯通。
- 默认 owner-only；任务、输入、成果、缩略图、下载和历史版本一致鉴权。
- 文件处理首版建议以 `.pptx/.docx/.xlsx` 与常规文本型 `.pdf` 为范围，具体支持矩阵待 C0 验证；扫描件、旧格式、加密文件及复杂对象单列能力边界，不默认承诺无损修改。
- 最小可交付技能：`image.generate`、`image.edit`、`presentation.create`；文件读取/修改按格式登记能力；只有实际能力验证通过才显示可用。

## 非目标

团队共享网盘、同步盘客户端、高级全文检索、目录树及在线内容编辑不作为本轮前置；多 Agent 团队是非前置；不做完整技能市场、计费智力值、外单交易、真实钱包结算、语音、视频制作/发布、自动部署、复杂画布/局部蒙版编辑器、在线幻灯片编辑器。PPT 内 AI 配图可选，首版不默认连带产生图片模型费用；优先复用用户素材与基础图形。

## 依赖与授权

先核对实际 Agent、图片生成/编辑工具、PPT 文件生成器、输入材料接入和可信成果生产路径。模型调用必须落在明确的账户/额度/资料外发授权内；本业务需求不是任意 Provider 付费授权，也不自动扩大此前排除的客户端改造范围。
