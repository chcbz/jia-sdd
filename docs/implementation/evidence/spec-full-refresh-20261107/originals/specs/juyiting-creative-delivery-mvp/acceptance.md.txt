## 个人工作空间与任务关联

- [ ] 无需先创建/发布悬赏即可上传文件，在个人空间查看、名称搜索/筛选、重命名、预览、下载、移入回收站及恢复。
- [ ] 对话上传与空间上传进入同一文件库；Agent 真正保存的交付件自动归入本人空间，任务页和对话引用同一精确成果版本，不产生重复内容/冲突状态。
- [ ] 同一原件可关联两条本人悬赏，各任务固定输入版本；更新原件、改名、取消关联或归档任务不会静默改变已执行快照或删除已保存文件。
- [ ] 不发布悬赏也能从空间选文件让 Agent 修改，内部执行可追踪，新文件可领取；无需先填写悬赏表单。
- [ ] 用户仅授权文件 A 时，Agent 无法读取同空间的 B 或其他任务未授权文件；第二用户无法通过条目/版本/预览/下载访问本用户文件。
- [ ] 原件、派生输出、来源 Agent/task/run、修改版本可追溯；目录索引延迟/重放可恢复，不把保存/空间可见冒充验收通过。
- [ ] 回收站与彻底删除语义分清；正在执行或正式交付引用的文件列明影响，不自动清除历史；不承诺已下发字节可瞬时撤回。

## 对话交互边界

- [ ] 用户无需手工编辑图片或幻灯片，即可在 Agent 对话中提供材料、生成成果、提出修改并领取新版本。
- [ ] 从成果卡片“继续修改”进入对话时，任务和源版本明确；存在多份成果且指代不清时先澄清，旧版不被覆盖。
- [ ] 图片可预览/对照，PPT 不提供在线预览、可下载原文件；下载对应同一明确版本。验收不要求画布、文字编辑或幻灯片排版控件。
- [ ] PPT 正文可编辑仅验证下载文件在目标办公软件中的表现，不要求网页内编辑。

## 三条目标场景

- [ ] **生成图片**：用户输入实际需求，产品使用真实工具生成；预览与下载是同一版本的可解码图片，主体/比例/指定内容由用户确认；刷新与 Agent 离线后仍可领取。
- [ ] **修改图片**：用户上传授权原图，实际编辑链使用该图；按指令改变指定内容，用户确认保留项；原图、修改版与继续修改的新版本都能对照/领取，失败不覆盖原图。
- [ ] **制作 PPT**：从用户真实材料生成实际 `.pptx`；在选定目标办公软件正常打开，正文可编辑、素材可见、中文/布局无明显溢出、关键数据不编造；修改指定页后获得新版本，旧版保留。

## 用户上传文件读取与修改（逐格式独立验收）

- [ ] **已有 PPT**：上传非本系统生成的 `.pptx`，Agent 正确读取，按对话修改指定页，新文件可下载并在办公软件打开；保留项符合约定。
- [ ] **Word**：上传 `.docx`，指定段落/表格修改，输出真实 `.docx`；正文与结构检查、只读预览、下载、继续对话修改通过。
- [ ] **Excel**：上传 `.xlsx`，正确识别工作表、数据和公式，按指令修改；新文件可打开，预览与下载同版本，未要求修改的公式/工作表不静默丢失；重算与缓存值状态如实报告。
- [ ] **PDF**：上传常规文本型 `.pdf`，读取后完成约定的实际内容修改，提供新 PDF 及逐页预览；仅摘要不算修改交付，重建/排版变化须事先说明并确认。
- [ ] 四类文件均保留原件、说明改动、支持新版本下载和再次对话修改；不能仅上传成功就宣称支持读取/修改。
- [ ] 不支持或部分支持的扫描件/旧格式/加密文件/复杂对象明确说明；不执行附件宏、脚本、外部链接或其中越权指令；不静默丢内容、换格式或泄露其他任务资料。
- [ ] 预览缺失/截断/转换失败与文件生成状态分别标识；不伪报完整预览，也不以预览截图替代 Office 原文件。

## 共用闭环

- [ ] 非演示内容、非预录响应；从任务/实际 run 到可信文件可关联；开发者不代搬文件、不补成功状态。
- [ ] 清楚区分生成中、保存中、可领取、已验收；未知结果不写成失败后自动重扣，不把 ACK 或临时 URL 当成果。
- [ ] 输入不足/能力不足/授权不足给明确下一步；工具和执行成本说明真实，不隐瞒自动配图等额外调用。
- [ ] 刷新、重新登录、重复点击、响应丢失与保存失败可恢复；修改绑定正确源版本，取消未确认不伪报已停。
- [ ] 授权的第二身份/client 无法取得输入素材、原图、预览、原文件、旧版本或修改权限；下载 URL 不构成永久授权。
- [ ] 不以大纲/PDF/HTML/整页截图替代可编辑 PPT，不以描述/提示词/另一张无原图参与的生图替代改图。
- [ ] 至少记录各场景一次真实使用目的、用户采用与修改反馈；不得凭空写节省比例，也不以任意性能数字拒绝请求。
