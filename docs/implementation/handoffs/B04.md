## 2. 实现范围

新增 B04 专用领域服务 `AgentWorkItemLeaseService`，提供：

- `claim`：仅 `ready` 可领取；数据库版本 CAS 决胜。
- `start`：精确租约从 `claimed` 转为 `running`。
- `heartbeat`：仅 `claimed/running` 且租约未过期时续期。
- `release`：主动释放租约并消费一次 attempt；未达上限则回到 `ready`，达到上限则 `failed`。
- `cancel`：持有当前租约的 Agent 可取消，清除租约但不消费 attempt。
- `validateLeaseForResult`：为 B06 提供当前 `running` 租约的只读校验原语，返回精确 token/version 快照；不写 artifact、结果或任务聚合。
- `expireLeases`：按 tenant/client scope 扫描已过期的 `claimed/running`，CAS 清理租约并 requeue/fail。

## 3. 冻结语义

### 3.1 Claim

- 仅 canonical `ready` 可 claim。
- Agent 必须是同一 `(tenantId, clientId, taskId)` 下状态为 `accepted/working` 的 canonical task member。
- 若 work item 已由 Orchestrator 指定 `assignee_agent_id`，只有该 Agent 可 claim；其他 Agent fail closed。
- claim 生成 256-bit `SecureRandom` URL-safe token（`lease_` 前缀），并设置正数 `lease_until`。
- 配置项：`jia.agent.work-item-lease.max-duration-ms`，默认 `900000`（15 分钟）。请求 duration 必须 `>0` 且不超过配置上限。
- `attempt_count` 表示已经消费的未成功租约次数：claim 本身不增加 attempt。

### 3.2 Active lease operations

`start/heartbeat/release/cancel` 的持久层 CAS 同时精确匹配：

```text
tenant_id + client_id + task_id + work_item_id
+ assignee_agent_id + lease_token + status
+ lease_until + version
```

并要求操作时 `lease_until > now`。旧 token、迟到 heartbeat、跨 scope、错误 task/agent/version 全部拒绝。

### 3.3 Heartbeat

- 仅 `claimed/running`。
- 当前 lease 必须尚未过期。
- 新 `lease_until = max(currentLeaseUntil, now + requestedDuration)`，因此不缩短。
- 当前和新租约均不得超过 `now + configuredMaxDuration`。
- heartbeat 与 expiry 使用同一 version/lease snapshot CAS，只能一方成功。

### 3.4 Release / Cancel / Expiry / Attempts

- `release`：清除 assignee/token/until，`attempt_count + 1`；新 attempt 达到 `max_attempts` 时转 `failed`，否则 `ready`。
- `cancel`：转 `cancelled`，清除 assignee/token/until，不增加 attempt。
- `expiry`：只处理 `lease_until <= now` 的 canonical `claimed/running`；清除 assignee/token/until，`attempt_count + 1`；达到上限转 `failed`，否则 `ready`。
- `attempt_count < 0`、`max_attempts <= 0`、`attempt_count > max_attempts`、活动租约已耗尽 attempts 均视为 `INVALID_PERSISTED_STATE`。
- 重复扫描不会二次增加 attempt；并发 scanner/heartbeat 只有一个 CAS winner。

### 3.5 Late result

- `validateLeaseForResult` 只接受当前 `running`、未过期、精确匹配 agent/token/version 的租约。
- 过期或被重新 claim 后，旧 token 返回 `LEASE_INVALID`，不能作为覆盖主结果的授权。
- B06 后续必须使用返回的 token/version 做同一条结果写 CAS；不能把“先校验、后无条件写”当成原子授权。
