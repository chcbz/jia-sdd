## 3. 验收语义

- dry-run/manifest 不猜测异常历史 ID；blocked 行保留供人工处置。
- approval 重新校验 staging 的长度、编码、枚举、row digest 与 batch digest，成功后 sealed manifest 不可变。
- apply 只消费 byte-exact operator 匹配的完整 `SEALED` batch，并在同一数据库原子单元写 issue/member/work-item/run。
- 普通 operator 无 audit/member/work-item 直接 DML，仅可执行批准的 `SQL SECURITY DEFINER` 入口；locked definer 与 12 个精确 trigger 形成纵深保护。
- 旧三表升级为四表时保留历史为 `LEGACY_UNSEALED`；旧 approval/run 不被提升为新 sealed 证据。
- initializer 合并保留 A08 identity validation 与 B09 四表、列、索引、collation、trigger body exact validation，不二选一。
