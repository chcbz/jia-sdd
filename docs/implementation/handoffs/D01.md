## 已冻结合同

- 权威表名：`agent_command_delivery`、`agent_outbox_event`、`agent_consumer_inbox`。
- 唯一键：delivery `(tenant_id, client_id, command_id)`；outbox `(tenant_id, client_id, event_id)`；inbox `(tenant_id, client_id, consumer_name, message_id)`。
- Outbox `message_id` 仅为非唯一查询索引，允许 broker redrive 复用。
- Delivery 保存业务 command bytes/hash；Outbox/Inbox 保存 byte-exact wire bytes/hash；类型为 `MEDIUMBLOB + BINARY(32)`。
- 已预留 retry、lease、CAS version、expiry、active message/attempt fence、publisher confirm、mandatory return、`WAITING_AGENT` 与 replay parent/requester/approver/reason。
- 三表禁止任何数据库 FK，包括同 schema、跨 schema 的入向和出向 FK。
