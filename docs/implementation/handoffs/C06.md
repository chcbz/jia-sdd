## Delivered contract

C06 adds a task-specific fetch-stream parser, strict immutable workspace reducer and recoverable composable. Event versions remain canonical decimal strings; `BigInt` is used only for exact comparison and increment. Snapshot is the only whole-state replacement, while allowlisted next events apply atomically and duplicates are idempotent. Gaps, redaction, malformed/unsupported payloads and incomplete projections trigger resync without partial state mutation.

Snapshot and stream requests always receive explicit immutable `taskId` and `actorAgentId`. The implementation uses authenticated `agentApi.execute` streaming rather than native `EventSource`, sends `Last-Event-ID`, fences snapshot/stream/timer/poll callbacks by generation, and safely handles visibility/focus recovery, bounded jittered retry, fixed-threshold degraded polling, deterministic terminal responses and default-off 503 behavior.

The SSE parser supports LF, CRLF, mixed line endings, arbitrary chunk/record coalescing, comments, multiline data and field ordering. UTF-8 line/record/data limits are enforced before unbounded parser allocation. Transport abort/cancel is idempotent and fail-safe for synchronous throws and rejected cancellation promises. Snapshot timeout is separately generation-owned because the shared HTTP client does not compose caller signals with its default timeout.

The workspace root uses immutable whole-state replacement through `shallowRef`, avoiding Vue proxy `structuredClone` failures while preserving root replacement reactivity.
