## Delivered contract

One immutable startup gate controls both workspace snapshot and task-event SSE. It defaults disabled; `enabled=true` requires a non-empty byte-exact tenant/client allowlist. Missing fields, sparse/empty entries, wildcard, exact duplicates, blank/Unicode-padded/control/invalid-surrogate/oversize values fail startup. Values are never trimmed, case-folded or normalized, and runtime property mutation does not refresh the gate.

The request boundary is authentication → direct required JWT claims → raw request syntax → gate → ACL → snapshot/replay allocation. Disabled or unapproved scopes return generic 503 with `private, no-store` and allocate no workspace transaction, ACL read, emitter, replay subscription, request worker/timer or DAO path. Successful SSE alone receives `X-Accel-Buffering: no`.

Bundled dev, grey, prod and test profiles each explicitly set `agent.task-events.enabled=false`; approved environments must override externally.
