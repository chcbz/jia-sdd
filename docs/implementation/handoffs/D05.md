## Settlement 与恢复语义

- 正常：claim ACQUIRED -> exact ACL -> raw WS send -> complete SENT -> ACK。
- offline：complete WAITING_AGENT -> ACK，不发布 Rabbit retry。
- prior terminal result：identity完全匹配后 ACK，无重复副作用。
- IN_FLIGHT、source-not-settled、ACL resolver unavailable、WS/DB transient：同 messageId/hash/raw bytes/provenance confirmed TTL parking；publish-first，best-effort complete(RETRY)，副本可在 source settle或lease到期后自动 reclaim。
- parking lane按 expiry安全降级 `5m -> 30s -> 5s`；source settlement retry独立于 delivery activeAttempt。
- confirmed parking失败时 transient保留原消息并 requeue；deterministic poison进入D04 DLQ。offline completion与所有parking同时失败时进入可审计DLQ，避免offline热循环。
- stateful双次消费测试覆盖 source settle、lease reclaim、offline recovery及DLQ provenance。
