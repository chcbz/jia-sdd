## Delivered contract

See `docs/implementation/preflight/C05.md`. C05 exposes `GET /agent/tasks/{taskId}/events` with explicit canonical `actorAgentId`, direct `JwtAuthenticationToken` `jiacn/client_id` claims, strict byte-exact route/cursor grammar, duplicate query/header rejection and max-cursor policy. It reuses the C04 browser ACL through a short read-only transaction that ends before replay allocation and consumes only `AgentTaskEventReplayService.replay(scope, cursor)`.

The 30-second SSE edge emits safe `task_event` frames with exact decimal-string versions and integral payload values, fixed redaction continuity, six terminal no-id resync reasons, own-member revocation close, no heartbeat/extra queue/thread/scheduler, and single bounded cleanup. Pre-send capacity/internal failures can return 503; once a send is attempted, failures are conservatively close-only. Every success/error, including security-chain 401/403 and MVC-equivalent matrix-parameter paths, receives `private, no-store`; successful streams also receive `X-Accel-Buffering: no`.

Production C05 has no Event DAO/Mapper/Broker/RabbitMQ dependency and leaves C03 byte-exact.
