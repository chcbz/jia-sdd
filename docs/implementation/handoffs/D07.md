## 身份、来源与锁序

- Inbox key：exact `(tenantId, clientId, consumerName, messageId)`；首个固定 consumer 为 `agent-command-dispatch-v1`。
- 服务对 defensive-copy 原始 wire bytes 自行计算 SHA-256，不接受 caller hash 为权威，不重序列化 JSON。
- 固定锁序：`delivery -> outbox -> inbox -> mutations`。
- DB delivery/outbox 是来源事实；校验 exact scope、eventId、commandId、deliveryId、messageId、wire bytes/hash、expiry 和 active message fence。
- outbox publish attempt 与 delivery transport/reissue attempt 明确分离。

## Claim / Complete

- `claim` 返回 `DISABLED | ACQUIRED(token) | IN_FLIGHT | PRIOR_RESULT`。
- 首次 claim 同一 `REQUIRED` 事务写 Inbox `PROCESSING`，并把匹配 delivery `PUBLISHED -> CONSUMED`。
- exact duplicate：terminal 返回 prior result；有效 lease 返回 in-flight；不重复 delivery 副作用。
- identity/hash/bytes/metadata drift、stored hash/bytes 或 terminal shape 损坏均 fail closed，且不打印 payload。
- lease reclaim 使用 activeAttempt/version fence；有效 lease不抢占，stale token不能完成。
- `complete` 同一 `REQUIRED` 事务更新 fenced Inbox 与 delivery disposition。
- `SENT` 只表示 socket send disposition，不等于 `RECEIVED`。

## 状态安全

- `rabbit-consume=true` 启动必须同时满足 `command-outbox=true + topology=true`；否则 startup fail-fast。
- OFF、DB_SHADOW 或 consume disabled 在 DAO 前停止；`DB_SHADOW_CAPTURE_ONLY` 永不写 Inbox或晋升。
- expiry 使用 authoritative delivery/outbox `expiresAt`；`now >= expiresAt` 才可 EXPIRED。
- stale marker 必须与当前 source stale fence 一致。
- `SENT` 无 error；失败类状态要求合法非空 ASCII bounded error code；EXPIRED/RETRY/lease/processedAt shape 全部 fail closed 校验。
- prior SENT 后 delivery 可合法前进到 RECEIVED/STARTED/SUCCEEDED/FAILED/EXPIRED/DEAD，精确重复仍返回 prior。
