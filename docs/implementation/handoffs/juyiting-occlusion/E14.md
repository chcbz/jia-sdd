## Integrity controls

- Runner removes an older report before every run, so failure is fail-closed.
- Report provenance binds the benchmark entry, runner, shim, test, and every
  `src/game/occlusion/*.ts` input by SHA-256.
- Browser identity includes `Browser.getVersion`, launcher/executable paths and
  SHA-256 hashes, UA, JS version, and protocol version.
- Runtime viewport is measured in-page instead of copied from fixture constants.
- Network evidence is collected from Chromium CDP events; artifact inventory is
  reported separately.
- Node/jsdom remains diagnostic-only and cannot satisfy the strict report test.

## Implemented optimizations

- SpatialGrid reverse index removes per-agent full-grid unregister scans.
- Per-kind cell index avoids materializing nearby non-zone entries.
- Same-cell agent updates avoid cell-key/Set allocation and reinsertion.
- Immutable constraint-zone neighborhoods are cached per scene/floor/query cell.
- Zone AABB + 3px hysteresis prefilter skips unnecessary exact geometry checks.
- Sparse prior membership persists outside the local query neighborhood.
- Static nodes/zone registry, compiled polygons, and inverse membership indexes
  are cached by authoritative identity.
- Deterministic Kahn ordering uses a binary min-heap.
- Redundant per-frame zone-cache allocation was removed.
