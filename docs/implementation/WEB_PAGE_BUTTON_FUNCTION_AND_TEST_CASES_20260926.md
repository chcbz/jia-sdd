## 7. 发布验收最小闭环

1. 先执行所有 P0 组件/集成用例，尤其 `FIND-01`～`FIND-04` 对应用例。
2. 前端正式测试与生产构建绑定 exact remote commit；按当前仓库政策由授权的 Flow 或临时本地发布流程执行。
3. 发布后执行：OAuth、聚义厅五热点、显式点将、聊天发送、任务详情、消息已读、公众号账号切换只读 Smoke。
4. 记录源 commit/tree、测试选择器、失败归因、制品 SHA-256、部署主机与线上健康结果。
