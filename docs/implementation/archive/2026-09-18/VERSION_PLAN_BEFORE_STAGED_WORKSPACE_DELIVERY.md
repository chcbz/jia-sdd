## 3. 1.10.0 明确承诺什么

**业务中心为个人工作空间**：用户可先上传、搜索/筛选、重命名、预览下载、查看版本和回收站恢复，再按需关联自己的悬赏。Agent 输出自动归入同一空间；一文件可给多条本人任务使用，各自固定输入版本。Agent 只领取本次授权文件，不能扫描整个个人空间。无公开悬赏的对话处理仍保留内部 task/run。详见 `specs/juyiting-creative-delivery-mvp/workspace-design.md`。

| 场景 | 最小用户输入 | 必须可领取的结果 | 验收反例 |
| --- | --- | --- | --- |
| 生成图片 | 需求、用途；可见风格/比例选项 | 实际生成图片、预览、原文件下载 | 只返回提示词/描述/样例图不算 |
| 修改图片 | 上传/选择原图，说明修改和保留要求 | 真实基于原图的结果，前后对照，原图与新版本下载 | 丢弃原图独立生成、覆盖原件不算 |
| 制作 PPT | 主题、用户文字/数据/图片、用途与受众 | 正常打开、正文可编辑的 `.pptx`，预览与版本历史 | 大纲/PDF/HTML/整套页面截图不能替代 |

新增文件范围：用户已有 PPT、Word、PDF、Excel 均纳入上传、读取和对话修改目标，不限定为本系统生成的文件。首版建议以 `.pptx/.docx/.xlsx` 和常规文本型 PDF 为支持范围；逐格式核实读取、修改、预览和导出，旧格式/扫描件/复杂对象不默认承诺。详见业务设计 §4.1。

共同流程：**上传/从个人空间选择材料（悬赏关联可选），对话提供需求 → 明确可执行 Agent/工具 → 真正生成/编辑 → 检查、保存并归入个人空间 → 预览/下载 → 对话提出修改 → 新版本 → 确认结果。**

**交互边界（用户最新补充）：以 Agent 对话生成和修改为主，界面只提供上传、状态、只读预览、下载与历史版本选择，不做图片画布或 PPT 内容编辑器。“继续修改”携带明确源成果/版本进入对话；PPT 正文可编辑指下载后的办公软件能力，不是网页编辑要求。

- 各场景/格式可分批交付，分别报告成功/失败/未测；一个场景上线不能宣称全量 MVP 完成。
- 使用自己的 Agent，默认仅 owner 任务。按实际能力路由，不强制三位 Agent，更不依赖多 Agent 编排。
- 原图/输入与输出一体鉴权；刷新/重新登录、Agent 离线后仍能取回已保存成果。
- 首版 PPT 可用用户材料和基础图形完成，不默认逐页付费配图；常规 Office/PDF 文件读取与修改纳入目标，任意格式无损处理、在线内容编辑器、视频/自动发布不在本轮承诺。
- 可编辑 `.pptx` 是本方案的实用性交付默认值，不表示已完成工具选型或兼容性验证。

## 5. 原模型/接单/技能需求的融合

- **模型展示**：有可信来源可在 MVP 显示；计费智力值与完整价格簿治理留到 1.11。
- **费用**：MVP 必须解释执行是否收费、谁承担、授权范围；未知不显示零。参考估算可渐进加入，不冒充实际用量；不能把四类文本 token 公式直接当图片费用。
- **接单**：默认 owner-only 与服务端隔离前置；外部 opt-in/邀请接受后置。
- **技能**：MVP 优先真实验证 `image.generate`、`image.edit`、`presentation.create`；有已验收成果后再做自动总结/确认目录。
- `juyiting-agent-model-governance` 原设计保留，规划至 1.11；安全原则继续约束 MVP，不要求先实现完整治理才生成第一个成果。

## 6. 非 Demo 的发布与验收要求

- 每类功能及每种声明支持的文件格式使用真实任务/输入，经真实工具执行产生非空文件，不以样例或 mock 验收。
- 图片可正常解码并符合用户约定，改图确实使用原图且保留项由用户确认；PPT 在选定目标办公软件可打开/编辑并核对资料和版式。
- 每条任务的状态、产物、修改、验收可追溯；保存失败/重复提交/结果未知/取消按实际工具能力恢复，不能重复收费或虚报成功。
- 用授权的第二身份/client fixture 验证输入、预览、原文件和历史版本拒绝；用户最终采用与技术发布分别记录。
- Owner 自检，不创建独立 Reviewer；应用测试/构建/发布遵循届时有效 Flow 政策或用户本地发布例外；Gradle 经 orchestrator 串行。记录实际 build origin、组件/运行时 exact source、测试、制品、配置与线上回读，不伪造 Flow Run。
- 不因任意慢请求阈值取消正常执行；真实网络错误、明确配置的传输超时、用户取消、权限/事务/锁归属继续保留。
- 客户端修改、Provider/资料外发与额度、生产数据变更若超出现有授权，应先明确范围。路线图与业务同意不是无限付费/生产授权。
