## Binding transaction and data packet

- Add a separate additive H05A schema/catalog/initializer for `archive_question`, `archive_question_event` and `archive_outbox`; do not enlarge H02/H03 all-or-none catalogs. Schema initialization and routes remain behind the existing default-off archive feature policy.

- The server locks authoritative ACTIVE content and reconstructs the selected UTF-8 bytes from 1..16 contiguous segments in one PREFACE/CHAPTER block, validates manifest/paragraph/selection hashes and code-point boundaries, joins slices with exactly two LF bytes and caps the result at 8192 bytes. Client `selectedText` is not trusted.
- Creation, authoritative selected-text snapshot, sequence-1 event, outbox row and byte-exact idempotent 202 response commit in one transaction. Same exact owner/method/path/key/hash replays without another event or dispatch; a different hash returns 409.
- State is `QUEUED -> RUNNING -> SUCCEEDED | FAILED_RETRYABLE | FAILED_FINAL`. Snapshot includes fixed responder, complete persisted answer, retry count, last error code, decimal-string version and current sequence.
- Outbox claim uses a lease and monotonically advancing fencing token. Provider work is always outside database transactions; only the current fencing token may persist answer events or terminal state. No unpersisted provider output is exposed. Maximum three attempts leads to `FAILED_FINAL`.
- Each event allocation locks the exact-scoped question row, increments `current_sequence` once and inserts the unique question-local sequence in the same transaction. Publication occurs only after commit and must be recoverable after a commit/process-crash window.

## Binding SSE packet

- Subscribe to the exact-scoped live source before database replay and allocate a bounded connection buffer.
- Capture persisted `replayWatermark`, replay `(Last-Event-ID, replayWatermark]`, merge/deduplicate by sequence, require exact-next continuity, drain buffered events above the watermark, then switch to direct live delivery.
- Cursor ahead, truncated history, gap, overflow or unverifiable continuity emits non-persisted `resync_required` without allocating a sequence and closes the stream. Heartbeats allocate no sequence.
- Disconnect, timeout/error, resync, feature disable and question switch atomically cancel subscription, replay/publisher work and heartbeat, clear buffers and prevent late writes to a closed emitter.
