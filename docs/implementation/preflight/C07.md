## Presentation ownership

Add a pure presentation surface under `src/components/juyiting/`, normally:

- `TaskWorkspacePanel.vue`
- `TaskTimeline.vue`

These components receive the frozen FE1 workspace, connection state and callbacks through props/emits. They do not import `agentApi`, call fetch, create streams/timers, parse versions, mutate the reducer, infer ACL, or duplicate workspace state. Do not integrate the legacy `CoordinationPanel.vue` and do not reintroduce SongJiang-only coordination actions.

## Information architecture

For an explicitly selected task and actor Agent, show:

- task summary and current connection/recovery state;
- members with canonical role/status presentation;
- work items and their status/assignee/progress fields;
- open/acknowledged requests;
- visible recent artifacts using safe projected metadata only;
- timeline in ascending event-version order;
- nullable conversation association as link/status only, without rebuilding chat;
- truncation indicators for timeline and artifacts.

A redacted timeline event uses one fixed safe message and displays only its version. Never derive or expose hidden type, actor, aggregate, payload, URI, content or metadata. Long identifiers/text wrap or ellipsize with an accessible full-label mechanism; do not inject HTML from payloads.

## State and actions

The component has explicit views for `idle`, `loading`, `live`, `reconnecting`, `degraded`, `resyncing`, `error`, empty collections and authorization unavailable. Recovery/retry emits one intent to FE1; the component never performs retries itself. No M2 business write API is added in this milestone.

Task and actor inputs are explicit. UI wiring may pass the current explicit choices, but it must never silently substitute a coordinator, first assignee, roster default or hidden last-selected Agent. Closing/changing either choice closes the surface through FE1.

## Responsive and accessible contract

- Operable by keyboard without pointer-only controls.
- Semantic headings, lists/tables as appropriate, labelled status regions and buttons.
- Connection/resync messages use `role=status` or a polite live region; fatal errors use alert semantics without repeatedly announcing retry ticks.
- Focus remains inside the existing Juyi Hall dialog rules; opening/closing the workspace must not introduce a second modal trap.
- Stable layouts at narrow mobile, tablet and desktop widths; no horizontal page overflow.
- Empty, 499-item bounded collections, 100-item timeline/artifact lists and extreme text remain usable.
- Respect existing colors/typography and reduced-motion behavior; no image generation is required unless a later visual review proves a missing asset.

## Juyi Hall integration invariants

- Keep `/agent/map` and `/agent/roster` separate and never call `/agent/active`.
- Existing task assignment continues to pass the clicked target Agent explicitly.
- Workspace is read-only and does not alter assignment, scene, chat or task-search flows.
- `conversationId` only links to existing discussion state; it does not create or switch conversations implicitly.
- Do not place M2 state into `CoordinationPanel.vue`, `useHallData`, scene composables or chat composables.

## C07F front-end feature gate

Use one build-time gate:

```text
VITE_JUYITING_TASK_WORKSPACE_ENABLED=false
```

Default and production files remain false. When false, the M2 workspace surface is absent, FE1 `open()` is never called, and there are zero workspace/SSE/poll/retry requests or timers; the entire M1 Juyi Hall remains usable. Approved test builds may set exactly `true`. Any other/missing value is false. No dynamic runtime override or query-string bypass.

When front-end true but backend returns its controlled disabled 503, show the bounded degraded/unavailable state and do not request-loop. Turning the build flag off and refreshing restores the untouched M1 path.

## Required acceptance probes

- pure components have no HTTP/SSE/timer/reducer imports
- all collections, empty states, truncation flags, connection states and safe redacted timeline text
- conversation link is association-only and null-safe
- keyboard navigation, labels/live regions/focus and long-text/mobile layout
- no raw HTML or hidden artifact/event fields rendered
- explicit task/actor props; no coordinator/assignee/selected-state fallback
- default-off/missing/invalid/true build flag behavior and zero M2 requests/timers while off
- controlled backend-disabled 503 causes bounded degraded display without loop
- map/roster/no-active/explicit-assignment regression tests
- focused component/composable tests, full `npm run test`, production `npm run build`, and `git diff --check`
