## Explicit authorization input

Every snapshot and stream call takes both `taskId` and `actorAgentId` as explicit immutable arguments. The composables must never infer actor identity from hidden global state, the last selected Agent, task assignee metadata, aliases or roster defaults. `open({taskId, actorAgentId})` changes generation whenever either byte-exact string changes. C07A may pass the currently explicit UI choice, but it must pass the value as an argument and close the workspace when no authorized actor is explicitly available.

Routes:

```text
GET /agent/tasks/{taskId}/workspace?actorAgentId=...
GET /agent/tasks/{taskId}/events?actorAgentId=...&sinceVersion=...
Last-Event-ID: ...
```

Use `agentApi.execute` with authentication, a caller-owned AbortController and `responseType: 'stream', streamChunks: true` for SSE. Do not use native `EventSource`, which cannot carry the required Bearer header.

## Version and reducer contract

Event versions are canonical decimal strings for their entire lifetime. Accept only `0|[1-9][0-9]{0,18}` within Java `Long.MAX_VALUE`; compare and increment with `BigInt` internally, but always publish/store/send strings. Never call `Number(version)` and never reuse scene `publishSceneVersion()`.

Snapshot replacement is the only path that replaces the whole workspace. It validates the bounded C04 DTO and `currentVersion`, then atomically replaces task, members, work items, open requests, artifacts, conversation link and timeline.

For a durable event:

- `event.version <= currentVersion`: duplicate, ignore with no mutation;
- `event.version == currentVersion + 1`: apply one allowlisted reducer transition and append/replace the timeline entry;
- greater, malformed, unsupported, out-of-order, payload-invalid or redacted-contract-invalid: do not partially mutate; request snapshot resync.

A server `resync_required` always reloads snapshot and never advances cursor. The reducer must not guess missing state from the bootstrap timeline.

## Stream parser and lifecycle

Implement a task-specific fetch-SSE parser that supports CRLF/LF record boundaries, chunk splits, comments and multiple `data:` lines. A truncated final record is never applied. Missing/duplicate/invalid id, invalid JSON, an event/data version mismatch, unexpected event name or resync with an id triggers resync/fail closed; do not silently skip malformed records.

Use an explicit generation for `(taskId, actorAgentId)`. Snapshot requests, streams, retry timers, polling timers and callbacks capture that generation. Switching task/actor, closing or unmounting aborts and clears all resources; late results are ignored.

Connection policy:

- states: `idle | loading | live | reconnecting | degraded | resyncing | error`;
- snapshot succeeds before opening the stream from its exact string cursor;
- network/EOF retries use capped exponential backoff with injectable bounded jitter;
- after a fixed consecutive-failure threshold, enter degraded single-flight snapshot polling;
- successful snapshot + stream/event resets failure count;
- polling never overlaps and never accelerates on failure;
- while document is hidden, do not create a new stream; on `visibilitychange` to visible or window focus, first validate/reload snapshot, then resume from the new cursor;
- 401/403/404 are terminal observable errors for the selected subject, clear stale workspace and do not infinite-retry;
- controlled 503/default-off becomes degraded/disabled state without request storm.

## C07A page integration

`JuyiHall.vue` keeps `selectedTask` and Agent selection as existing UI state only. One watcher passes explicit `{taskId, actorAgentId}` into `useTaskWorkspace`; identity changes restart, object-identity-only task mutations do not. A null task or actor closes and clears the workspace. Unmount stops it.

C07A exposes the frozen workspace and observable state for FE2 but does not implement the presentation panel. It must not alter:

- map Agents from `/agent/map`;
- roster Agents from `/agent/roster`;
- the prohibition on `/agent/active`;
- explicit target-Agent task assignment;
- existing scene/chat connection state or timers.

## Required acceptance probes

- exact strings above `2^53`, `Long.MAX_VALUE`, duplicate, next, gap and out-of-order reducer paths
- snapshot as the only whole-state replacement and no partial mutation on invalid event
- CRLF/LF/chunked/multiline/comment/truncated/malformed SSE records
- snapshot/stream connection-window race without loss or duplicate application
- task/actor A->B aborts old snapshot/stream/timers and generation rejects late callbacks
- capped exponential backoff+jitter, fixed failure threshold, single-flight polling and successful recovery
- hidden/visible/focus behavior and complete stop/unmount cleanup
- 401/403/404 terminal behavior, controlled 503 degradation and no request storm
- explicit `actorAgentId` in every request and no hidden inference
- regression tests preserve map/roster separation, no `/agent/active`, and explicit assignment target
