## Route and authorization

```http
GET /agent/tasks/{taskId}/events?actorAgentId={canonicalAgentId}&sinceVersion={eventVersion}
Accept: text/event-stream
Last-Event-ID: {eventVersion}
Authorization: Bearer ...
```

The authorization subject is exactly `(JWT.jiacn, JWT.client_id, path.taskId, query.actorAgentId)`. Read claims directly from `JwtAuthenticationToken`; do not use `EsContext`, username/sub/aud/client aliases, defaults, selected UI state, persona/runtime names or WebSocket identity. Inputs are byte-exact, bounded, unpadded and control-free. Reuse the C04 strict browser access guard: active direct canonical owned non-built-in Agent, exact scoped task, exact member row, and member state in `accepted | working | blocked | done | failed`. All absent/foreign/inactive/alias/coordinator-only/non-member/invalid-state cases are one generic 404.

Authorization is a short read-only transaction that returns an immutable authorized subject. The transaction must end before creating the emitter or subscribing replay. Never hold a DB transaction across an SSE connection.

## Cursor contract

Receive both cursors as raw strings. Each present value must match `0|[1-9][0-9]{0,18}` and be in `[0, Long.MAX_VALUE]`. Blank, padded, leading zero, sign, decimal, exponent, Unicode digit, overflow, duplicate query parameter or repeated/comma-joined header is 400. Validate both independently; if both are present, use numeric `max(query, header)`. Do not clamp cursor-ahead; C03 emits `CURSOR_AHEAD`.

## Replay and wire contract

C05 consumes only `AgentTaskEventReplayService.replay(scope, cursor)`. Production C05 code must not reference the event DAO, Mapper, Broker or RabbitMQ and must not modify C03.

Durable frame:

```text
event: task_event
id: <exact decimal eventVersion>
data: <safe JSON projection>
```

Visible data contains decimal-string `version` and `occurredAt`, safe event ID/type/actor/aggregate fields and an allowlisted JSON-object payload. Never emit scope columns, DB IDs, raw `eventJson`, credentials or arbitrary metadata. Revalidate the projection; one serialized data object is capped at 16 KiB UTF-8. For an ACL-hidden artifact event, preserve continuity with exactly `{ "version": "N", "redacted": true }` and expose no other event field.

Resync frame:

```text
event: resync_required
data: {"currentVersion":"N","reason":"cursor_ahead|history_gap|retention_gap|page_gap|replay_budget_exhausted|durable_state_unprovable"}
```

A resync frame has no `id`, is emitted at most once, and closes immediately. If the actor's own canonical member is left/rejected, emit that durable event and close before any later queued event; the next connection must re-authorize.

## Resource and lifecycle contract

- Fixed emitter timeout: 30 seconds; no heartbeat timer.
- Per connection: one emitter, one C03 subscription, immutable authorized subject, atomic terminal/cleanup state.
- No additional queue, `onBackpressureBuffer`, cache/replay/share, `collectList`, per-connection thread/scheduler, unbounded executor or second transport buffer.
- Completion, timeout, cancel, IOException, send failure, backpressure, capacity, shutdown and resync all dispose exactly once and forbid later send.
- Never advance an SSE `id` before that durable frame is actually sent.
- Pre-first-frame capacity/backpressure/internal failure is generic 503 where the HTTP response is still mutable; after any SSE byte, close only and append no JSON/error/resync frame.

## C05F feature gate

```properties
agent.task-events.enabled=false
agent.task-events.allowed-scopes[0].tenant-id=tenant-a
agent.task-events.allowed-scopes[0].client-id=client-a
```

One gate wraps both workspace and events. Default is disabled. `enabled=true` requires at least one exact tenant/client tuple; wildcard, duplicate, blank, padded, control-character, oversize or empty allowlist configuration fails startup. No trim/case-fold/normalization and no runtime refresh. All bundled profiles explicitly remain false; approved test environments override externally.

Request order is authentication -> required claims -> request syntax -> feature gate -> ACL -> snapshot/replay allocation. Disabled requests return one generic 503 and create zero workspace transaction, ACL read, emitter, replay subscription, broker lease, timer, worker or DAO read. Existing C03 singleton construction is outside this request-allocation guarantee. M1 map/roster/assign/report/scene/chat behavior and flags remain unchanged.

## HTTP and cache boundary

- 400 malformed route/actor/cursor
- 401 invalid or absent resource token
- 403 valid JWT missing/invalid `jiacn` or `client_id`
- 404 generic unauthorized/unavailable task subject
- 503 flag disabled, pre-stream capacity, or safe-projection/integrity failure
- 200 SSE then EOF for timeout/cancel/post-first-byte failure
- 200 SSE + one no-id resync frame then close for C03 resync

Every success and error, including security-filter 401, carries `Cache-Control: private, no-store`. Successful streams also carry `X-Accel-Buffering: no`; do not set hop-by-hop `Connection`.
