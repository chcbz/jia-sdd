- `agent_task_member`
- `agent_task_work_item`
- `agent_task_request`
- `agent_task_artifact`

- identity registry/alias：A02
- thread：B07
- event：C01
- outbox/inbox/delivery：D01
- Entity/DAO：B02
- 历史回填：B09

## 字段与约束建议

`agent_task_meta` 增加：

```text
collaboration_mode
risk_level
max_agents
coordinator_agent_id
review_required
task_version
current_event_version
```

work item 增加 `required_item`、`submitted_at`、`completed_at`；artifact 的业务唯一键必须包含 `artifact_version`。

所有 Agent 引用使用 ADR-001 定义的 canonical agentId；所有协作表显式保存 tenant/client scope，其中当前 `tenant_id` 对应 jiacn 逻辑主体。

## 工程约束

项目当前没有 Flyway/Liquibase，B01 必须同步维护：

- `task-collaboration-schema.sql`
- `schema.sql`
- `AgentSchemaInitializer`
- Schema 测试
- 部署迁移说明

MySQL 当前版本支持较新语法，但后续 Outbox claim 建议使用 CAS，不把 `SKIP LOCKED` 作为基础假设。
