## Immutable schema

Public content tables must not extend tenant/client `BaseEntity` and must not carry owner scope columns.

- `archive_work`: byte-exact `work_id` PK, title, nullable `active_edition_id`, timestamps.
- `archive_edition`: byte-exact `edition_id` PK, `work_id`, `STAGING|READY` import state, source/manifest digests, frozen counts/byte lengths, import/activation timestamps.
- `archive_chapter`: one ordered content block per edition, including preface as `block_type=PREFACE`, `reader_ordinal=0`, nullable chapter number; chapters use `block_type=CHAPTER`, ordinals/numbers `1..120`. External `block_id` is unique per edition.
- `archive_paragraph`: edition/block scoped external paragraph ID, ordinal, immutable UTF-8 text, byte length and SHA-256.

`archive_work.active_edition_id` is the sole ACTIVE pointer. Schema SQL resource and runtime initializer must be byte/shape parity-tested against MySQL `information_schema`, including binary-safe collations, NOT NULL rules, foreign keys and index order. No destructive down migration or update-in-place text path is allowed.

## Deterministic importer and activation

1. Verify packaged manifest file SHA, internal manifest SHA, source metadata SHA, schema version, exact IDs, counts, byte lengths, paragraph hashes and both excluded notice lines.
2. Insert target edition as STAGING and import blocks/paragraphs in bounded batches without holding the work row lock for the whole import.
3. Existing rows are byte/hash compared. Exact rows are idempotent; any differing title/order/text/hash/length/count fails closed and is never updated or deleted.
4. Mark the edition READY only after a full persisted re-read proves all 120 chapters, mandatory preface and 3677 reader paragraphs.
5. Activation is one short transaction: lock `archive_work(work_id)`, lock candidate edition, revalidate READY/digests/counts, then switch `active_edition_id`. Rollback leaves the previous pointer unchanged.
6. Parallel import/activation, partial batch failure, process restart and stale STAGING rows must converge without exposing partial content.
