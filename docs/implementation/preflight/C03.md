- Date: 2026-08-16

- Same branch/worktree and Writer as C02

## Frozen boundary

C03 consumes C02 wakeups only as lossy high-water hints and always reconstructs truth from MySQL. It adds bounded paged replay, live-first bridging, exact continuity validation and `resync_required`. It does not add HTTP/SSE endpoints, browser ACL, workspace snapshot, or feature flags.

## Required state flow

```text
subscribe local wakeups
-> read scoped durable high-water
-> validate cursor/history
-> paged DB replay
-> coalesce duplicate/out-of-order wakeups
-> catch up until durable high-water
-> live
```

Cursor ahead, retention/history gap, non-contiguous page, replay budget exhaustion or inability to prove continuity must produce `resync_required`; never guess or synthesize missing events. Add an explicit page limit to the existing unbounded `findAfterVersion` path. Versions stay exact Java `long` internally and become decimal strings only at the later HTTP/Web boundary.

## Required failure tests

- connection window write between live subscription and initial DB read
- dropped, duplicate and out-of-order local wakeups
- cross-instance/no-wakeup recovery through bounded durable high-water checks
- cursor ahead, missing first event, middle gap, retention truncation and page boundary gaps
- cancellation/unmount cleanup of broker subscription, worker, timer and in-flight catch-up
- concurrent catch-up coalescing without unbounded queueing
