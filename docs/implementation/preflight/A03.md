## 当前风险

- `agent_direct_message` 同时承载普通聊天和执行命令。
- `/home/isp/apps/codex-ws-agent/agent-client.mjs` 会对 direct message 执行 Codex，并在结束后发送 `task.report`。
- 客户端发送 `codex.result`，服务端当前没有对应处理分支。
- Agent 忙碌时新消息可能直接丢失。
- `task_event`、direct command 等多个入口可能重复触发执行。

## A03 建议边界

A03 只负责协议分类、Envelope、Normalizer、服务端兼容 handler 和相关测试；不越界实现：

- A05：客户端持久队列，聊天不产生 task.report；
- A06：ACK 与幂等；
- A04：WebSocket scope/target 隔离；
- B08：旧 report 到新领域状态的适配。

## Protocol v1 候选类型

```text
protocol.hello
agent.register
agent.presence
chat.message
chat.message.delta
command.dispatch
command.ack
work.progress
work.heartbeat
work.result
help.request
artifact.publish
task.event
protocol.error
```

冻结原则：只有 `command.dispatch` 可以触发执行；`task.event` 只能更新状态/视图，不得触发命令执行。A03 正式实施时需结合 ADR-001 携带 canonical agentId 和 runtimeInstanceId。
